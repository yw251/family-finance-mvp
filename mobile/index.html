每月一次，五步完成

  • 1填写收入工资 / 副业 / 投资理财 / 其他，可跳过稍后补
  • 2上传截图微信 + 支付宝月度汇总账单，每平台 ≤9 张
  • 3确认结果核对金额校验、分类与金额，修正漏识别
  • 4补充支出银行卡 / 现金等渠道支出手动补录
  • 5完成复盘生成统一月报，约 5-10 分钟
全部流程本地完成，数据不出设备。历史月份可随时回看报告。

隐私说明

数据保存在当前浏览器收入、分类、月报和识别结果存储在当前设备的浏览器中，不会同步到云端。
截图仅在本地识别应用不接入微信或支付宝账户，也不会读取支付平台的逐笔交易。
请只上传分类汇总请勿上传包含交易对象、商品名称、账号等信息的逐笔交易明细。
清理浏览器数据、使用无痕模式或更换设备都可能导致记录丢失，建议定期导出完整 JSON 备份。
