# 家财月报 MVP v0.7.2

通过微信、支付宝月度汇总截图完成本地 OCR 识别、人工确认与统一月报。

v0.7.2 在 v0.7 外部试用能力之上补充真实脱敏截图指引，并优化电脑与手机网页布局；手机确认结果按单条记录卡展示，优先呈现确认状态、平台分类和金额。外部用户任务指标与独立测试集结果仍在收集中。

手机端建议使用最新版微信内置浏览器、Safari 或 Chrome；若仍看到旧样式，请刷新页面缓存。

## 隐私说明

- 截图识别在用户当前浏览器中完成。
- 账目和截图保存在用户浏览器本地，不写入本仓库或 GitHub Pages。
- 清除浏览器数据或更换设备可能导致本地数据丢失，请及时导出备份。
